# PokeLearn Lesen

Die Vorlese-Seite von PokeLearn: Sie hört dem Kind direkt über das Mikrofon zu und prüft Wort für Wort, was gelesen wird.
PokeLearn öffnet diese Seite mit dem Lesetext im Link; am Schluss zeigt die Seite einen Lese-Code, den das Kind in PokeLearn eingibt.

Die Seite wird aus PokeLearn erzeugt (gleiche Lese-Engine) und über GitHub Pages ausgeliefert.
